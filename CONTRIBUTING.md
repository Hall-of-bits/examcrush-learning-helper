# Contributing

Thanks for helping improve a Digital Public Good–aligned learning helper.

## Dev setup

```bash
npm install
npm test
npm run build
npm run demo
```

## Guidelines

- Keep the **offline heuristic path** working without API keys.
- Preserve **source spans** on every generated item.
- Do not add network calls or analytics by default.
- Add/adjust tests in `tests/` for generator and export changes.
- Discuss large features in an issue first.
